# Simple C++ Programs

This folder contains simple C++ programs for beginners. These programs are useful for learning basic programming concepts and practicing C++.

## Topics Covered

- Input and Output
- Variables and Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Arrays
- Strings
- Basic Number Programs

## Example Programs

- Addition of Two Numbers
- Subtraction of Two Numbers
- Multiplication of Two Numbers
- Division of Two Numbers
- Largest of Three Numbers
- Even or Odd Number
- Positive or Negative Number
- Leap Year Check
- Prime Number Check
- Factorial
- Fibonacci Series
- Palindrome Number
- Armstrong Number
- Reverse a Number
- Swap Two Numbers
- Sum of Digits
- Matrix Addition
- Matrix Multiplication
- Binary to Decimal Conversion
- Decimal to Binary Conversion

## Requirements

- C++ Compiler (G++, GCC, MSVC, etc.)

## How to Compile and Run

```bash
g++ filename.cpp -o output
./output
```

For Windows:

```bash
g++ filename.cpp -o output.exe
output.exe
```

## Purpose

This folder is created for beginners to practice basic C++ programming and improve problem-solving skills.
